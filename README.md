# 交易 Agent

一个用于产品演示的中文多智能体交易业务工作台。交易主理人会根据问题调度日常运营、商品运营、招商、营销活动和项目管理五个专家 Agent，并在界面中实时展示工具调用和生成结果。

## 能力

- 浏览器内模拟 manager-style 多 Agent 调度
- 确定性的流式回答与执行事件
- 内置确定性交易业务演示数据
- KPI 表格、诊断报告、项目计划和 CSV 导出
- 黑白线框三栏工作台与移动端抽屉
- GitHub Pages 静态部署，无需登录或后端服务
- 定时任务管理：通过对话新建、编辑任务，支持列表查看、启用／暂停与删除

## 定时任务演示

侧栏进入「定时任务」，列表展示任务名称、执行时间和操作。点击「新建」回到首页，输入框预填「帮我创建定时任务：」，补充「每天上午 9 点生成昨日运营日报」并发送即可创建。支持每天、每周、工作日，以及指定日期或今天／明天的一次性任务，时间统一按北京时间处理。

为便于直接评审列表效果，首次使用或旧版空列表会加载三条可编辑的示例任务；删除后刷新不会恢复。可通过 `?view=scheduled` 直接打开列表。对于「每周一早上发我一份上海当周的天气预报」这样的描述，会明确建议每周一 09:00，回复「确认」后保存，也可补充其他具体时间。也支持直接输入「每天9点生成日报」，无需固定前缀。

点击任务名称回到原对话底部；点击「编辑」同时预填「帮我修改这条定时任务，」，可以补充「改成每天 10 点执行」「执行内容改为查询北京今日气温」或「名称改为运营日报」。未提及的配置保留，新建和编辑成功后默认启用。开关切换后在页面上方提示结果，删除需要弹窗确认，也可用右上角关闭按钮或取消退出。

任务及来源对话保存在当前浏览器的本地存储中，刷新后保留。旧版任务没有来源对话时，根据已有配置恢复对话并明确说明。此功能用于交互演示，不调用真实模型、不执行定时任务、不发送飞书消息。自然语言识别采用前端规则，缺少信息或时间表达不明确时会提示补充，可发送「取消」退出草稿；保存失败时可发送「重试」。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。演示不需要 API 密钥，刷新页面后会清空当前对话。

## 验证

```bash
npm test
npx tsc --noEmit
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布 GitHub Pages。

所有业务数据均为虚构演示数据，应用不会连接、读取或修改真实业务系统。
